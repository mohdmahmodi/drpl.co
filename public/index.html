drpl.co

Simple, private file sharing across all your devices on the same network.

How It Works

Local Network Discovery: Devices on the same WiFi appear automatically — no setup required.

Direct Transfer: Click a device to send files or messages directly, peer-to-peer.

Private by Design: Files never touch external servers. Everything stays on your local network.

Zero Setup: No installs, no accounts. Just open the site on both devices.

Troubleshooting

Devices not showing? Make sure both are on the same WiFi. Disable VPNs if active.

Transfer failing? Firewalls can block WebRTC. Try Chrome or Edge for best compatibility.

Ad blockers may interfere with device discovery — try disabling them for this site.
