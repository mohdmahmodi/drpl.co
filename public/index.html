          About drpl.co

          Open drpl.co on two devices connected to the same network. They find each other automatically. Click a device to send files or messages. The receiving device has to accept before anything is sent, and the files then move directly between the two devices, encrypted.

          The server introduces the devices to each other and gets out of the way. The one exception is when a firewall or VPN blocks the direct connection: drpl then relays the data through the server so the transfer still works, and says so in the Transport row while it happens.

          Transfer

          Method WebRTC data channel, device to device
          Consent Receiver accepts first, or it expires after 60 seconds
          Encryption DTLS, built into WebRTC
          Chunk size 64-256 KiB, negotiated
          Size limit None enforced
          Fallback Relayed through the server if WebRTC is blocked

          Privacy

          Files Never stored, and never sent to the server at all unless the relay fallback is in use
          Server role Discovery and connection setup only
          Third parties None. No CDN, no analytics, no fonts loaded remotely
          Discovery Devices grouped by network address
          Accounts None
          Tracking None
